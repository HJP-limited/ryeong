### 답변 품질 2종 — Faithfulness / Answer Relevancy

**멀티턴 전용이다. 검색 지표와 섞지 않는다.** 검색(`eval_search.py`)은 LLM을 부르지 않으므로
이 둘을 잴 수 없고, 재서도 안 된다 — 검색은 '가져오기'를, 이 둘은 '가져온 것으로 무엇을 했나'를 잰다.
둘 다 **LLM이 실제로 답을 만든 턴**에만 매긴다(체크리스트와 같은 범위).

| | 표준 정의 (RAGAS, Es et al. 2023) | 표준 구현 | 우리 적응 |
|---|---|---|---|
| **Faithfulness** | 답변의 주장 중 컨텍스트가 뒷받침하는 비율 | LLM이 주장을 쪼개고, LLM이 각 주장을 컨텍스트와 대조 | 답변이 **필드 값 모양**이라 주장 = 필드 값. 전화·이메일은 정규식, 회사·부서·주소는 1000장에 실재하는 값이 답변에 나타나는지로 뽑고, **그 턴의 프롬프트에 들어간 카드**(`context_cards`, narrow 전) 안에 있으면 근거 있음 |
| **Answer Relevancy** | 답변이 질문에 부합하는가. 불완전·딴소리면 낮음 | LLM이 답변에서 질문 N개를 역생성, 원 질문과 코사인 유사도 평균 | 질문은 '누구의 어떤 속성'이다. 요청 필드마다 **그 유형의 값**이 답변에 있나 (출처는 묻지 않음). 속성 없는 질문은 컨텍스트 인물을 언급했나. 정답이 있는데 거절하면 0 |

**왜 판정자 모델 없이 재도 되나.** RAGAS 논문도 주장 분해가 가장 불안정한 단계라고 적는다.
우리 답변("데이터플랫폼팀입니다", "010-3000-6000")은 분해가 필요 없을 만큼 짧고 정형이라
결정적으로 쪼갤 수 있다. 그래서 **재현 가능하고, 판정자 모델의 편차가 없다.**

**세 층은 서로 다른 것을 잰다** — 같이 읽어야 진단이 된다.

| 층 | 묻는 것 | "회사 물었는데 주소 답함" | "남의 회사 답함" | "날조 번호" |
|---|---|---|---|---|
| Answer Relevancy | 맞는 **종류**인가 | 0 | 1 | 1 |
| Faithfulness | **컨텍스트에서** 왔나 | 1 | 0 | 0 |
| 체크리스트 | 맞는 **값**인가 (정답 카드) | 0 | 0 | 0 |

처음엔 관련성을 "컨텍스트 안의 값"으로 쟀다가 충실성과 겹쳐서 고쳤다. 관련성은 **유형만**
봐야 세 층이 분리된다. 합성 사례 7개로 경계를 확인했다(전부 기대와 일치).

**한계(정직하게).** 데이터에 없는 회사명을 지어내면 못 잡는다 — 색인이 없어서다. 전화·이메일
날조는 정규식으로 잡힌다. 직함·이름은 2~3자라 부분 일치 오탐이 커서 충실성 주장으로 세지
않는다(관련성 유형 판정에는 쓴다). 컨텍스트 = 그 턴의 카드이고 대화 이력은 포함하지 않는다 —
이력에는 있지만 이번 카드에 없는 값을 쓰면 근거 없음으로 본다. **그게 바로 "옛 인물 값"
실패 모드다.**


**측정 결과 (386턴 덤프, LLM 턴 349개)**

| 지표 | 값 | 분모 |
|---|---|---|
| Answer Relevancy | **0.952** | 314/330 요청 필드 (정답 카드 있는 턴만) |
| Faithfulness | **1.000** | 272/272 주장 · 233턴 (주장 0건 116턴 제외) |
| 연락처 날조 없음 | **1.000** | 349/349 |

**채점기를 먼저 의심했다.** 첫 채점은 관련성 0.793 · 충실성 0.886 · 실패 121건이었는데, 실패
목록을 읽어 보니 **105건이 채점기 오탐**이었다 — `프로덕트디자인팀` 안의 `디자인팀`을 별도 주장으로
셈, `우암로 1`이 `우암로 144`에 매치, 같은 핵심어의 다른 카드로 정규화, 2글자 직함(차장·과장)을
색인에서 누락, 속성 생략 후속(`어민서씨도?`)을 '누구 찾기'로 분류, 정답 없는 턴(잡담·진술)에
관련성을 매김. `--dump` 덕에 **재생성 없이** 네 번 고쳐 다시 쟀다(각 3초). 남은 16건은 전부 실제
결함이다: `직장/어디 다녀`를 회사로 못 읽음 5 · `{n}씨도?/어때?/그럼 {n}씨는?`에 이름만 답함 5 ·
복수 후속에 이름만 나열 4 · `부서는?`→`총 1명` 2. 충실성 1.000은 "컨텍스트 밖 값을 쓴 턴이 0"이라는
뜻이지 완벽하다는 뜻이 아니다 — 데이터에 없는 회사명 날조는 이 방식으로 못 본다.

**측정 재현.** `--dump`로 턴별 (질문·답변·컨텍스트 카드·정답)을 JSONL로 남긴다. 채점 기준을
바꿔도 **생성 없이** 다시 잴 수 있다 — 생성(75분)과 채점(초)을 분리한다.

## 거부한 지표 — 4개

전부 **측정해 보고** 뺐다. "안 맞아서"가 아니라 "재 보니 이래서"다.

| 지표 | 제안 | 거부 이유 (측정값) |
|---|---|---|
| Exact Match | 외부 | 우리 답변 **40턴 전부 0.000**인데 값은 다 맞다. 라벨·쉼표 차이를 재는 지표다 |

## 발표 문장

> 자체 회귀망은 1.000으로 유지되고, 성능 개선은 외부 고정셋에서 25/50 → 47/50으로 확인했다.

| 재측정 필요 | |
|---|---|
| pass^3 1.000 (표본 18) | 발화 다양화 이후 `--repeat 3` 을 다시 안 돌렸다. 체크리스트·관련성·충실성·무관 억제(0.900, 9/10)는 다양화 이후 전량 값이다 |
